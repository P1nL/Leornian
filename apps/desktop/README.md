# Desktop

技术：React、TypeScript、Vite、Tauri 2；JavaScript 与 Rust 依赖已初始化和锁定。

负责对话、课时、编辑器、练习和公开工件展示。通过 HTTP、快照和 SSE 读取服务端公开状态，不直接访问数据库，不自行认定评分、掌握度或任务完成。

公开 API 与事件类型由服务端 schema 生成，避免手工维护第二套相同合同。刷新与重连恢复服务端快照，不从本地 UI 推导业务事实。

## 本机产品形态（待实施设计）

2026-11-03 确认仅本机执行，不提供远程 Runner。应用、本地后台及学习记录均在用户电脑；此处“服务端”表示本机业务权威，模型 API 仍由用户自配并按用途调用外部服务，不代表完全离线。

正式使用顺序为：安装 Leornian → 检测/引导准备一次本机隔离引擎 → 按所学语言一键准备课程环境 → 路线需要框架时展示依赖/版本/资源和权限 → 用户授权后自动准备/验证 → 本机运行。拒绝/稍后安装保留路线和教材，不将未就绪练习标可用；同范围环境重建复用，超范围变更再确认。

语言支持/可信配方内置，不捆绑全部 SDK，不修改全局工具链。正式应用负责本地后台启停，不要求学习者使用下面的开发命令。首次引导、环境授权/进度及一键安装尚未实现，详见 [第四阶段 spec](../../docs/phase-4/spec.md) S13 和 [IMP](../../docs/phase-4/imp.md) WP11。

## 当前功能

- 本地匿名开发身份、创建学习目标、服务端目标与任务状态、已提交事件列表。
- Bearer 令牌仅在请求头传递；使用 fetch 流读取 SSE，不把令牌放进 URL。
- 初始加载与重连先读取一致性快照，再从该游标订阅事件；刷新不丢失已保存目标。
- 提交前持久保存幂等键；响应丢失后以原内容重试不会创建第二份业务结果。
- 按所选目标展示 Tutor 对话、运行状态和工具读取次数，支持取消与已记录回执承接。没有独立模型配置时明确禁用发送，不制造模拟回复。
- 教学工件支持排队生成、基于精确版本修订、读取历史/当前版、取消与承接；独立检查通过才显示正文。工件按当前目标/节点过滤，HTML/脚本/代码均作为转义文本，不执行。工具进度显示安全名称、结果与耗时，不显示原参数、推理或内部回执。
- 教学可选择目标、精确确认节点/课时或已公开反馈；显示候选检查/修复/等待/合格交付，不把未通过候选当正式回复。等待信息时在原任务补充；取消覆盖后续修复，UNKNOWN 不显示盲目重试。
- 可加载更早对话和计划版本；合格路线仍需明确确认，合格课时不标记学习完成。不改变原有暖色侧栏/工作区视觉体系。
- 在同一 Tutor 输入区选择教学或路线规划；动态草案、明确确认版本、历史版本和来源链接均来自服务端，不在客户端组装假路线。
- 已确认路线选择节点后生成带版本引用的正文，安全文本展示解释/代码/回想问题；代码不执行，不在阅读后自行标记完成。
- 节点题包/版本/盲解六审状态、明确本地发布、练习与锁定反馈；补救仅已分配后打开，考核仅服务端 ready 后明确 start 才入 DOM。修订与超长审核格式补正不设次数上限，原回执与已有裁决保留。
- 概念 Gate 准备/开始/整组提交/取消、失效恢复、原题不可重考提示；考核中暂停 Tutor 和新训练请求。仅服务端精确计划版本的概念进度显示完成，不根据单题正确或模型文字解锁下一节点。
- 独立性失败可关联原 Gate 继续题包修订，仍完整盲解/六审；不设修订版数上限，同材料不重复刷审、不分叉重开根链。
- 补救错误后明确请求不同情境后继，展示服务端选择/打开/一次提交/取消；开题前不显示候选，缺题提示补齐已审核材料。后继答对只满足补救前置，不直接标记学习完成。
- 自动缺题需求持续修订、合格发布并准备精确后继关系检查；ready 后仍由学习者明确打开/作答。显示 running/waiting/completed/cancelled、当前修复动作与恢复原因，不把版本次数当失败条件。
- 题包记录默认跟随当前自动 head，显式选择历史后保留选择，可返回当前供给进度。停止入口针对整个供给任务，等待任务可在更新授权/来源/配置后恢复；已取消任务不续跑，已发布和旧报告保留。
- 以已锁定回执启动唯一 Tutor 讲评，显示公开解释/回想，不自动抢占用户问题或改分。提示先讲评再选后继，避免教学上下文变化后继续使用旧关系许可。
- 五槽 Python 执行题、真实盲解资格状态、一次训练程序提交、绑定补救、两程序整组 Gate、submitted 等待和独立执行反馈。程序在 Runner 而非浏览器/宿主执行；刷新恢复本人已提交程序，不显示隐藏测试或盲解解法。
- 执行补救失败后的代码后继、缺题供给/同类型修订/明确发布；复用后继面板显示程序一次锁定、等待/终态/取消，不把后继答对显示成 Gate 通过。普通训练不能绕过已分配后继再答同题。
- 固定 Python 计划确认、课时阅读、代码提交和服务端作答反馈；只有服务端三组用例全部通过才展示本课完成。
- 目标关联摘录的新增、修订、七天使用确认和撤销；明确标注学习者提供、未抓取或独立认证。
- 完成本课后展示复习卡，服务端到期后允许回想/自评，支持暂停/恢复；自评只更新日程，不当作掌握度。
- 沿用旧受保护原型的暖色、侧栏/工作区语言；没有复制或修改原型文件。此页不是整套产品视觉重做。

## 命令

新生题入口默认自动链：需求提出后只展示版本、盲解/审核和停止原因，跟随同链后继；不要求手动修订、格式补正、继续六审或发布。保留取消入口；旧手动题包仍展示兼容操作。自动发布不会在页面读取考核题或创建作答。偏好可留空，节点/题型要求仍来自最初业务需求。

从仓库根目录执行 `pnpm dev`，打开 <http://127.0.0.1:5178/>。Vite 将 `/v1` 代理到 8088，生产静态页和 Tauri 默认直连 `http://127.0.0.1:8088`；可在构建前用 `VITE_API_BASE_URL` 修改。

`pnpm check`、`pnpm test`、`pnpm build` 分别进行类型检查、SSE/内容静态渲染测试和网页构建。类型由服务端 schema 生成，先运行 `pnpm contracts` 同步，不手工编辑 generated.ts。

`pnpm desktop:dev` 用于实际启动桌面开发窗口；需要 Rust/MSVC/WebView2 和未占用的 5178 端口。若网页开发服务已在运行，先结束它再启动 Tauri，以免 beforeDevCommand 发生端口冲突。

此前切片验证过 Tauri `cargo check`，本轮未改 Rust、未重新构建原生窗口或安装包。应用图标由 `icons/source.svg` 经 Tauri CLI 生成 Windows ICO，不是最终品牌定稿。

上述 Rust 和首次浏览器目标提交检查来自前一切片；当前 React 24 项测试、类型与构建通过，覆盖此前隐私/锁定边界、完成驱动供给、历史选择、候选/合格交付语义、UNKNOWN 与原任务信息补充，以及工件脚本转义、空值绑定和接收/交付区别。静态渲染不等于交互/视觉验收。内置浏览器此前受限，新增页面没有桌面/手机截图或原生窗口验收，也未换入口绕过。

会话令牌保存在 localStorage，当前不提供正式注册、账号恢复或跨设备登录；本地身份与目标只属于新 Leornian 库。
