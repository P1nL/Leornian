# ADR 0001：独立仓库与无 Sidecar 的原生架构

- 日期：2026-10-30
- 状态：架构方向已确认；分阶段实现中，当前交付见根 README
- 项目：Leornian

## 背景

用户决定新建仓库重构整个项目，重新划分功能、数据归属和模块通信，而不是继续在旧执行链上累积专用修复。

## 决策

1. 使用独立新仓库与新库，暂不迁移旧学习记录、表和运行状态。
2. 旧 Aearn 仓库、数据库和历史证据保留，不作为新系统必须直接读取的运行依赖。
3. 移除 Sidecar，不建设 Codex 适配器、双运行时选择或备用入口。
4. Tutor、原生 Agent Runtime 与业务模块分离，业务模块拥有自己的数据和最终裁决。
5. 模块化单体业务代码起步，API/Worker 共享业务包，隔离 Runner 独立运行。
6. 同进程使用类型化公开接口，长工作使用持久任务，跨模块通知使用已提交事件。
7. 业务进度、外部调用事实、当前权限分别保存，消息重投不是重复外部调用的许可。

## 取舍

- 不承担旧表和旧运行状态的直接兼容，初期也不展示旧学习记录。
- 自主维护模型循环、上下文、工具路由与恢复机制，但不重造通用编程 Agent 的所有功能。
- 不通过给每个模块增加网络接口来假装解耦。
- 具体接口、表和目录仍随实现收敛，完整说明以架构基线为准。

## 本次落地

2026-10-30 最初仅初始化本地 Git 仓库、文档和基础目录。2026-10-31 已落地通信、原生 Runtime、固定学习闭环、来源摘录和基础复习，未创建远程仓库或提交；后续实施不改变上述架构决策。
