# ADR 0001：独立仓库与无 Sidecar 的原生架构

- 日期：2026-10-30
- 状态：架构方向已确认；分阶段实现中，当前交付见根 README
- 项目：Leornian

## 背景

用户决定新建仓库重构整个项目，重新划分功能、数据归属和模块通信，而不是继续在旧执行链上累积专用修复。

## 决策

1. 使用独立新仓库与新库，暂不迁移旧学习记录、表和运行状态。
2. 旧 Aearn 仓库、数据库和历史证据保留，不作为新系统必须直接读取的运行依赖。
3. 移除 Sidecar，不建设 Codex 适配器、双运行时选择或备用入口。
4. Tutor、原生 Agent Runtime 与业务模块分离，业务模块拥有自己的数据和最终裁决。
5. 模块化单体业务代码起步，API/Worker 共享业务包，隔离 Runner 独立运行。
6. 同进程使用类型化公开接口，长工作使用持久任务，跨模块通知使用已提交事件。
7. 业务进度、外部调用事实、当前权限分别保存，消息重投不是重复外部调用的许可。
8. 2026-11-01 用户明确要求生题内部自动闭环，并进一步要求以合格完成为目标，不按固定修订版数或格式补正次数停止。正常流程自动生成、验证、按实际报告修订与合格发布，缺题需求继续准备可分配后继；质量条件不放宽。旧手动记录不接管，不靠重审不变材料刷绿。
9. 2026-11-03 用户确认只做本机代码执行，不提供或预留远程 Runner。应用、本地后台、数据及执行环境均在用户电脑；模型 API 由用户自配，可按用途调用外部服务。基础语言支持/可信配方内置，实际课程环境按需准备；路线所需框架/依赖经明确授权后自动安装到专用隔离环境，不修改系统全局 SDK。同范围环境重建复用，超范围依赖/权限再确认。

## 取舍

- 不承担旧表和旧运行状态的直接兼容，初期也不展示旧学习记录。
- 自主维护模型循环、上下文、工具路由与恢复机制，但不重造通用编程 Agent 的所有功能。
- 不通过给每个模块增加网络接口来假装解耦。
- 具体接口、表和目录仍随实现收敛，完整说明以架构基线为准。

## 本次落地

2026-10-30 最初仅初始化本地 Git 仓库、文档和基础目录。2026-10-31 已落地通信、原生 Runtime、固定学习闭环、来源摘录、路线/正文和基础复习，按用户要求创建本地基线提交 `d883984`，未建远程或推送。其后新增概念题包质量链，用户明确授权复用旧仓库密钥用于本项目；旧学习数据/运行状态仍不迁移。后续实施不改变上述架构决策。
